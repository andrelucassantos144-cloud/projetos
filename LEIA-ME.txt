ESTRUTURA DO PROJETO
--------------------

└── includes/              Header, footer, auth, funções


COMO INSTALAR (XAMPP — Windows)
-------------------------------
1. Instale o XAMPP: https://www.apachefriends.org/download.html

2. Copie a pasta "projeto-corinthians" para:
   C:\xampp\htdocs\

3. Abra o XAMPP Control Panel e inicie:
   - Apache
   - MySQL

4. Acesse o phpMyAdmin: http://localhost/phpmyadmin

5. Clique em "Importar" e selecione o arquivo:
   database/corinthians.sql

6. Abra o site no navegador:
   http://localhost/projeto-corinthians/

7. Área administrativa:
   http://localhost/projeto-corinthians/admin/login.php
   E-mail: admin@corinthians.local
   Senha: admin123


CONFIGURAÇÃO DO BANCO
---------------------
Se necessário, edite includes/config.php:

   DB_HOST = localhost
   DB_NAME = corinthians_db
   DB_USER = root
   DB_PASS =          (vazio no XAMPP padrão)
