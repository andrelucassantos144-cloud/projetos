Como abrir o site Corinthians

Instruções para usar em outro computador

Não abra o index.html com duplo clique!
Esta página é só o manual. Para ver o site completo, siga os passos abaixo.

Etapa 1 — Instalar o XAMPP (primeira vez)

  1. Acesse apachefriends.org/download
  2. Baixe e instale o XAMPP para Windows
  3. Conclua a instalação (não precisa configurar nada)

Etapa 2 — Iniciar o site

  1. Feche esta aba
  2. Na pasta do projeto, dê duplo clique em:
    iniciar-servidor.bat
  3. Mantenha a janela preta aberta
  4. O navegador abrirá em http://localhost:8000/

Se der erro

  1. Instale o XAMPP se ainda não instalou
  2. Execute o iniciar-servidor.bat dentro da pasta projetos
  3. Leia o arquivo LEIA-ME.txt na pasta

Arquivos de ajuda na pasta:
COMO-ABRIR.txt — guia rápido
LEIA-ME.txt — manual completo (Windows, Mac, Linux)

Vai Corinthians!
